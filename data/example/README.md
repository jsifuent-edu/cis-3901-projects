# data/example

`penguins.csv`: data for the worked example in `example/`, written from the R package with `write_csv(palmerpenguins::penguins, "data/example/penguins.csv")`. One row per penguin, 344 rows.

- **Source:** Horst, A. M., Hill, A. P., & Gorman, K. B. (2020). *palmerpenguins: Palmer Archipelago (Antarctica) penguin data* (R package). <https://allisonhorst.github.io/palmerpenguins/>
